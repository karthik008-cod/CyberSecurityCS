Task 6: Reporting and Legal Considerations

      
Follow a 3-tier escalation path and generate an official formal complaint.


      

        

          Tier 1
          
Social Media

          

            Report profile for harassment. Request IP log preservation. Block only after saving evidence.
          

        


        

          Tier 2
          
College ICC

          

            Report to Internal Complaints Committee (ICC) & Proctor for campus security escort and attendance safety.
          

        


        

          Tier 3
          
Police / Cyber Cell

          

            File FIR under IPC 354D (Stalking) & IPC 506 (Intimidation). Call 1930 or visit cybercrime.gov.in.

            1. Freshman Induction Module:
            
30-minute mandatory orientation on OSINT risks, privacy settings, and EXIF metadata.

          


          

            2. Peer Cyber Ambassadors:
            
Student-led audit clinics in dorms to help peers turn profiles private and set up 2FA.

          


          

            3. Confidential 24/7 Helpline:
